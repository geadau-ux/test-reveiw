API 金鑰與型號

1．選擇 AI 服務
2．輸入 API 金鑰

3．選擇型號
在手機上設定金鑰（只要做一次）
  1. 到 Google AI Studio 取得金鑰用 Google 帳號登入，按「Create API key」建立。
  2. 在金鑰旁按複製圖示，再回到這個頁面。
  3. 按上方金鑰欄旁的「 貼上」，再按「測試連線」。
  4. 勾選「記住金鑰」，按「儲存設定」。之後打開就能直接用。
金鑰安全
金鑰只存在這個瀏覽器裡，分析時由瀏覽器直接送到 Google 或 Anthropic，不會經過其他伺服器。費用依各家 API 計價，由金鑰擁有者支付。
